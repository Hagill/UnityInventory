## 주요기능

- 기능 1
    - Unity-UI-Framework를 이용한 UI간의 전환을 스택으로 구현

- 기능 2
    - Character.sc의 내용으로 GameManager.cs에서 player 생성 및 player의 스탯을 각 UI에 반영

- 기능 3
    - SO로 작성된 아이템 데이터들을 player의 inventory 리스트에 적용

- 기능 4
    - player의 inventory 리스트를 가져와 UIInventory에 적용 및 갱신

- 기능 5
    - 아이템 타입에 따른 중복 장착 허용 X

- 기능 6
    - 경험치, 레벨업 버튼으로 레벨에 따른 캐릭터의 스탯을 실시간으로 확인 가능
